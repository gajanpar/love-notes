# SPKTAD PT Pelindo Multi Terminal Branch Cirebon

Sistem Penilaian Kinerja Tenaga Alih Daya (SPKTAD) untuk evaluasi berkala pegawai alih daya PT Pelindo Multi Terminal Branch Cirebon.

## Panduan Deployment 100% Pure Free (Tanpa Kartu Kredit)

Repositori ini telah dikonfigurasi penuh dan teruji untuk **3 platform hosting 100% gratis tanpa kartu kredit (Zero Credit Card / $0 Selamanya)**:
1. **Alwaysdata** (Pilihan Utama: Full Persistent Laravel, SQLite/MySQL, SSH & Artisan CLI)
2. **Vercel** (Alternatif 1-Klik: Instant GitHub Import, Serverless vercel-php)
3. **InfinityFree** (Cadangan: Traditional Apache cPanel, .htaccess routing, free MySQL / SQLite)

Lihat dokumentasi lengkap di [DEPLOYMENT.md](DEPLOYMENT.md).
